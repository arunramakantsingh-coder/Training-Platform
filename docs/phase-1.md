# Phase 1

## Goal

Establish the repository and deployment foundation for the three platform components.

## Deliverables

- Training Website directory and container definition
- Lab Controller directory and container definition
- Lab Interface directory and container definition
- Docker Compose foundation
- Deployment documentation
- Architecture documentation
- Environment example

## Current state

The containers are intentionally minimal placeholders. They establish boundaries and a repeatable container deployment model; application functionality will be implemented in subsequent phases.
