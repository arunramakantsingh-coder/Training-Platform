# Development Workflow

1. Plan work using the GitHub Project and repository issues.
2. Implement changes in a feature branch.
3. Commit changes to GitHub.
4. Review the pull request.
5. Merge the completed work into `main`.
6. Pull the selected revision into the EVE-NG VM.
7. Deploy and test there.
8. Record defects or follow-up work as GitHub issues.

The VM is a deployment and test environment. GitHub is the source of truth for application code.
