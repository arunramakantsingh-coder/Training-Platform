# AI Troubleshooting Rules

## One Step at a Time

When troubleshooting infrastructure, virtualization, networking, deployment, configuration, or coding issues with Arun:

1. Analyze only the information currently available.
2. Give exactly one next troubleshooting step at a time.
3. Wait for the user to provide the result before giving the next step.
4. Do not jump ahead to later commands, fixes, or validation steps before the current step has been completed.
5. Avoid presenting a long troubleshooting sequence when the next step depends on the current result.
6. When coding, follow the same incremental approach: inspect/validate the current state first, then make the next smallest change.
7. Keep troubleshooting focused so unnecessary chat usage/credits are not consumed.
8. Clearly distinguish what is confirmed from what is still unknown.
